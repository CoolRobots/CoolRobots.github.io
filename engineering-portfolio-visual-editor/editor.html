Portfolio visual content editor

Edit your website text and project photos using forms. No HTML editing needed.

How saving works: Changes stay in this editor until you click Download content.json. Upload the downloaded file to the root of your GitHub repository, replacing the old content.json, and commit. GitHub Pages will update automatically. This editor does not ask for your GitHub password or publish by itself.

Images: Upload photos to your repository (for example assets/senior-robot.jpg) using GitHub's Upload files option. Then enter that exact path in the project's Image field. Image uploads aren't automatic.

Privacy: this is a static editor running in your browser. Do not publish private contact information you don't want on the public web.
